## 📌 Descrierea proiectului

**EcoTrack** este o aplicație creată pentru a încuraja oamenii să protejeze mediul înconjurător și să adopte un stil de viață ecologic.

Aplicația prezintă activități prin care utilizatorii pot contribui la protejarea planetei, precum reciclarea, economisirea apei și utilizarea transportului public.

Scopul proiectului este de a demonstra că fiecare persoană poate contribui la un mediu mai curat.

## 🎯 Obiectivele proiectului

- Încurajarea reciclării.
- Reducerea poluării.
- Economisirea apei și energiei.
- Promovarea transportului ecologic.
- Protejarea naturii.

## 🚀 Instalare și utilizare

Pentru a descărca proiectul, folosește următoarea comandă:

```bash
git clone https://github.com/username/EcoTrack.git
```

Intră în folderul proiectului:

```bash
cd EcoTrack
```

Deschide fișierul `index.html` în browser.

## 🌍 Importanța proiectului

Protejarea mediului este responsabilitatea tuturor.

Poluarea, defrișările și risipa resurselor naturale afectează planeta și generațiile viitoare.

Prin EcoTrack, utilizatorii sunt încurajați să adopte obiceiuri responsabile și să contribuie la un viitor mai bun.
